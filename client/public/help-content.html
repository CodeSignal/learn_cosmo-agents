Your coding agent

This workspace comes with an AI coding agent. Ask it to read, explain, change and test the code in the project, the same way you would in the agent's own app.

What is set up for you

  • The agent works inside this task's project folder.
  • The models, permissions and tools available are fixed for this task. Settings that are locked show as unavailable in the agent's settings.
  • If the task offers more than one agent, pick one from the list at the top.
